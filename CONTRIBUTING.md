# Contributing

Small improvements and real migration pitfalls are welcome. Open an issue describing your Access version, the command, the expected result and what actually happened.

Please use a minimal synthetic example when reporting bugs. Never attach a customer database, credentials, internal server names or screenshots with personal information.

A focused change with a brief explanation of why it matters is more useful than a large rewrite. If you want to support a new Access field type or target database, document what can be verified and what still needs the Windows Access application.
