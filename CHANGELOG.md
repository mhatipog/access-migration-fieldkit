# Changelog

## 0.1.0 — 2026-10-29

First public version.

- Read-only MDB/ACCDB inventory and checksum-verified JSONL extraction.
- SQLite landing database with source row ordinals and per-value reconciliation.
- Source metadata assessment, optional MDB Tools probe, PostgreSQL example and SQL Server/SSMA guides.
- Preserves duplicate records, Null/empty distinction, exact Access Currency and binary values during export.

Validated with two independently generated native Access database files on Linux/Oracle ARM64. Not a frontend/VBA converter, and not yet a production client migration.
